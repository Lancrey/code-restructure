# Sample Report

This directory contains the 2 sample reports generated after the skill was run on https://github.com/Lancrey/PolyFaceLib and the final Architecture Validation report, after the suggested modifications have been applied.

## Documents

- `Architecture audit — PolyFaceLib`: analyse the current structure (layout, dependencies, path-pinning files, findings) and gives additional recommandations.
- `Migration plan — PolyFaceLib`: design a target layout with an exhaustive relocation table and a migration sequence with compatibility measures, validation strategy, risks and decisions needed from the user.
- `Architecture Validation`: contains a summary for stakeholders, the list of what changed, reference, compatibility shims and items excluded and not verified.
